2. Upload EVERYTHING inside this abir-portfolio folder to the repository root.
3. In Netlify choose Add new site / Import an existing project, then connect the GitHub repository.
4. Build command: leave empty. Publish directory: .
5. Deploy the site. Do NOT use Netlify's manual drag-and-drop deployment for this project: the Admin Panel depends on Netlify Functions.
6. Open https://YOUR-NETLIFY-SITE.netlify.app/admin/ and sign in with the temporary credentials above.

8. Edit content and press the real Save button. Changes are stored in Netlify Blobs and persist across browsers/devices.
